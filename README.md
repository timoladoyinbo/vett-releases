# Vett

Vett is a desktop app that checks a website the way a careful reviewer would. It runs a real Chrome or Edge window through the site and checks it against recognised standards: WCAG 2.2, OWASP, Core Web Vitals, the GDS Service Standard and more. You get a report with evidence, which you review before sharing.

This repository holds Vett's installers only. Download them from [Releases](https://github.com/timoladoyinbo/vett-releases/releases).

## Install

Vett needs **Google Chrome** or **Microsoft Edge**.

- **macOS:** open the `.dmg` and drag Vett to Applications. The builds aren't signed yet. On first launch, go to **System Settings › Privacy & Security** and choose **Open Anyway**.

Pre-releases are test builds and don't update automatically.

## Privacy

Sites, specs, findings, screenshots and keys stay on your computer. See [USAGE-AND-PRIVACY.md](USAGE-AND-PRIVACY.md) for what Vett sends and how to turn it off.
